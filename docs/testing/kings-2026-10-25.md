## Pre-existing Windows test failures

An unmodified archive of HEAD `3b9c191cf0537de6c3bb42405dc3090ba52c1616` was built separately.
Running `ServerOperationsTest,SecureConnectionTest,CardMatchIntegrationTest` reproduced
**34 tests, 1 failure, 3 errors** before any King code:

1. A Unix-rooted path assertion compared a drive-relative Windows path with the normalized
   absolute configuration result.
2. Control-socket and encrypted-backup tests unconditionally queried POSIX permissions on NTFS.
3. The untrusted-authority TLS test replaced its database field without closing the previous
   connection; Windows then refused to delete the temporary SQLite file.

Only test harness corrections were made: normalize the expected path; assert POSIX permissions
when the filesystem supports them (all socket/backup behavior still executes); close the first
database before starting the second TLS server. No test was disabled or skipped, and no
production permissions, TLS, backup or persistence behavior was relaxed.
