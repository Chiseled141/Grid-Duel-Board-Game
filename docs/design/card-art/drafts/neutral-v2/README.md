# Neutral card design draft

Visual proposal only, generated with the built-in image generation tool. The existing
blacksmith card is a style reference, not a card to replace.

- Spell example: Reconnaissance, with a scroll icon and slim charcoal-indigo frame.
- Landmark example: an unnamed architectural illustration, with an arch icon and a
  sandstone frame. LANDMARK is a placeholder label; no name or balance effect is approved.
- Neither type carries a national crest, class tag, printed points, or play cost.
- Both keep the manuscript illustration style and portrait card proportions.

The draft does not replace the runtime catalog or assets. Existing art remains until
the user reviews the draft. The existing Unit types are BOWMEN, CHAPLAIN, ENVOY, FOOTMEN,
KNIGHT, PIKEMEN and RIDERS. The final five types have not been chosen, so do not guess which
two classes to remove.
