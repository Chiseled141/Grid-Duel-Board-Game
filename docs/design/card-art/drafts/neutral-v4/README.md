actions and numbers use bold emphasis. Manuscript artwork, neutral frames, descriptions
and the no-humans Spell direction remain. The font is generated lettering resembling
a modern humanist sans-serif, not a verified embedded font family.

major labels use sans-serif lettering. Landmark name and bonus remain placeholders.
This is a review draft only; no runtime art or previous sources were replaced or deleted.
