# Complete neutral Spell draft set

Individual visual drafts use the modern-font neutral-v4 style. No people, nationalities,
printed points or costs. Working names and concise text are for review; unspecified
targeting and edge cases do not become approved rules through these images.

The requested effects are Disable Tags, Disable Points, Destroy Unit, Random Discard,
Random Steal, Draw Two, Exchange, Reconnaissance, Sabotage, Spy and
Clear Disable. Recall is excluded. Individual files and their full prompts are saved here.

The six provisional Landmarks have a separate draft set. The all-seven-nations bonus is
a base combo. Existing runtime art and Unit classes are not replaced by this draft pass.

Destroy Landmark was rejected and removed from this set. Landmarks persist throughout the match; Sabotage only suppresses them for one round.
