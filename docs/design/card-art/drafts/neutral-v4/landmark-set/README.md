# Provisional Landmark artwork

Six individual draft cards: Embassy, Guild Hall, Armory, Ruined Keep, Archive and Watchtower.
The user accepted these names and effect directions for now. Numeric bonuses, the weaker
Unit threshold and unresolved interactions remain deferred. No numeric bonus was invented
for the descriptions. All seven nations is a base combo, not a Landmark effect.

The neutral sandstone arch frame and modern sans-serif descriptions follow the approved
visual draft. Built-in image generation produced each card separately; full prompts are
saved beside the PNGs. Existing runtime art and catalog are unchanged.
