# Protocol 16 compatibility fixture

`protocol16-frame.ser` is a Java-17-target serialized empty `PlayerView` created from the
repository's pre-King HEAD (protocol 16). Both sides have `Row.EMPTY`, `Scoring.score(Row.EMPTY)`,
zero counters and empty private/event/result lists; seat/turn are FIRST, revision 0, round 1,
phase IN_PROGRESS, and outcome/lastPlay are null. It contains no account or live match data.

It was generated by compiling that HEAD's core records and writing the view with
`ObjectOutputStream.writeObject`. `ReplayPersistenceTest` stores the actual old bytes and checks
that the current server returns its incompatible-version response while preserving the record.
