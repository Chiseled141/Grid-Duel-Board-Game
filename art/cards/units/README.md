# Unit source artwork

The 35 canonical Unit PNGs live in the five class folders below this directory. Open [gallery.html](gallery.html) to compare the complete set by nation.

## Nation color pass — 2026-10-21

Replaced generic red faction fabric and painted panels on 30 source cards using the built-in imagegen editor, preserving the existing medieval illustration style and composition. The palette follows each card's existing border:

- Austria: royal blue
- Bohemia: purple
- Croatia: teal
- Hungary: green
- Poland: crimson red (five original files left unchanged)
- Styria: gold
- Transylvania: charcoal

This pass replaces the existing PNGs in place. Runtime JPGs were not updated by this pass. It changes artwork colors only; rules and printed badges were not changed. In particular, Riders still print 7, as the user chose to preserve badges during this color pass.

[generation-prompts.json](generation-prompts.json) records the exact prompts and built-in generation mode. [verification.json](verification.json) records file dimensions, hashes, and whether each source changed. All 30 edits were visually reviewed as generated; the automated checks cover file inventory, dimensions, and hashes, rather than pixel-perfect preservation.
